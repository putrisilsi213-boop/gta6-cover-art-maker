Vice Sunset Cover Studio: turn your photo and a caption into a multi-panel sunset poster cover, offline in your browser, exported as a PNG to share. Diagonal hero, four-panel and hero-plus-strip layouts, four sunset/neon colour grades, per-panel crop and positioning, bold gradient caption lettering, and the common post sizes 1080 x 1080, 1080 x 1350 and 1920 x 1080. Photos never leave your machine; all art is drawn in code — original, no game logos, artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load a photo (or tap a sample), pick a layout and grade, edit the caption, and Export PNG.
